# Apple Music 链接助手

在 Apple Music 网页播放器上补齐原生界面缺少的链接工具：复制专辑 ID、按区域复制链接、按区域跳转。

## Language

### 页面与标识

**区域（Region）**:
Apple Music 链接路径开头的两位商店代码，决定页面内容与语言，如 `jp`、`hk`、`us`、`cn`。
_Avoid_：国家、地区、地域

**专辑（Album）**:
Apple Music 上以数字标识的作品集合页面。
_Avoid_：唱片、album

**专辑 ID（Album ID）**:
专辑页面链接末尾的数字。歌曲页面的链接里，这个数字仍是专辑 ID。
_Avoid_：页面 ID、歌曲 ID

**歌曲 ID（Song ID）**:
链接中 `?i=` 参数的值，指向专辑内的单曲。它不是脚本复制的对象。
_Avoid_：曲目 ID、单曲 ID

**歌单（Playlist）**:
以 `pl.` 开头的字符串标识的播放列表页面。歌单没有专辑 ID。

### 操作

**复制 ID（Copy ID）**:
把当前页面的专辑 ID 写入剪贴板。页面没有专辑 ID 时，这个入口不出现。
_Avoid_：复制页面 ID

**复制链接（Copy Link）**:
把当前链接的区域换成目标区域后写入剪贴板，保留 `?i=` 参数。下拉框的初始项只作标签用，不能选；操作结束后回到这个初始项。
_Avoid_：复制地区链接、复制分享链接

**切换区域（Switch Region）**:
跳到同一页面在目标区域下的地址，参数保持不变。
_Avoid_：改地区、换国家

**手动输入（Manual Entry）**:
用键盘输入区域代码。它与区域下拉占同一位置，二者只出现一个。
_Avoid_：自定义区域、自定义地区

**反馈提示（Feedback）**:
页面底部短暂出现的操作结果文字。
_Avoid_：toast、提示框

### 页面结构

**动作行（Action Bar）**:
标题下方承载原生操作按钮的一行。脚本入口插在这一行内播放按钮的后面。页面上没有播放按钮时，脚本也不出现。
_Avoid_：按钮区、工具栏
